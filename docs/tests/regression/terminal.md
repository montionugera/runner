# Terminal

Use bounded scratch output/receivers and the [procedure](../full-smoke-test.md). For native input checks, keep screenshots plus exact received bytes or scratch file contents. Physical IME composition, native selection and modifier-click must be observed in the development app. A replay, pasted Chinese, CLI metadata or a successful automation call does not establish those behaviors. Restore clipboard/input-source changes without committing private contents. Stop every bounded helper before ending the run.

Current authority: [terminal element/input](../../../crates/runner-app/src/terminal/element.rs), [authoritative model](../../../crates/runner-terminal/src/terminal/model.rs), [mirror/bridge](../../../crates/runner-terminal/src/terminal.rs), [resize](../../../crates/runner-app/src/terminal_resize.rs) and [PTY runtime](../../../crates/runner-daemon/src/session/pty_runtime.rs).
